# Mon site web

Site web statique (HTML / CSS / JS).

🔗 **Site en ligne : https://cartelface-droid.github.io/site-web/**

## Aperçu local

```bash
python3 -m http.server 8080
```

Puis ouvrir http://127.0.0.1:8080/

## Fonctionnalités

- Menu de navigation avec sous-menu déroulant pour la Galerie.
- Le déroulant s'ouvre au survol sur desktop et au clic/tap sur mobile (`script.js`).

## Déploiement

Hébergé via GitHub Pages depuis la branche `master` (racine `/`).
Chaque `git push` sur `master` redéploie le site automatiquement.
